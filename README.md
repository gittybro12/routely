# Routely Abuja

A simple React + Vite app for mapping Abuja car parks and public car routes.

## Features

- Map display using MapLibre GL
- Car park selection and route preview
- Transfer points and next-leg guidance

## Setup

1. Install dependencies:

   npm install

2. Run development server:

   npm run dev

3. Open the local URL shown by Vite.

## Notes

- The app uses manual sample data for Abuja car parks and along routes.
- Replace placeholders with real route data or connect to a transport API to expand coverage.
