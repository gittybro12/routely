Routely project details and dev notes.

- Local dev server: `npm run dev -- --host 0.0.0.0`
- Build: `npm run build`
- Main files:
  - src/App.tsx
  - src/Map.tsx
  - src/data.ts
  - src/styles.css

Notes:
- The `data.ts` file contains the car park list and route graph.
- Use the `getAssistantResponse` helper for assistant-style replies.
